Häufige Fragen (FAQ)

Wie aktiviere ich meinen PRO-Schlüssel?

Nach dem Checkout wird Ihr persönlicher Schlüssel (z. B. VELO-XXXX-XXXX-XXXX-XXXX) direkt hier auf dem Bildschirm angezeigt und per E-Mail zugesendet. Klicken Sie im Velo-Browser-Popup auf „Lizenzschlüssel eingeben“ und fügen Sie ihn ein.

Werden meine gelesenen Texte an Server übertragen?

Nein. Velo arbeitet vollständig clientseitig in Ihrem Browser. Die Sprachausgabe nutzt die Web Speech API Ihres Betriebssystems. Es werden zu keinem Zeitpunkt Dokumente oder gelesene Texte an externe Server übertragen.

Auf wie vielen Geräten kann ich Velo PRO nutzen?

Jede Lizenz kann gleichzeitig auf bis zu 2 persönlichen Computern (z. B. Arbeits-PC und privates Notebook) aktiviert werden.

Kann ich mein Abo jederzeit kündigen?

Ja. In jeder E-Mail-Rechnung von Paddle befindet sich ein direkter Link zur Abonnementverwaltung. Sie können mit einem Klick kündigen, und Ihr Pro-Zugang bleibt bis zum Ende des bezahlten Jahreszeitraums aktiv.
